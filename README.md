
# Madurai Travelss — Starter Website

A premium multi-page travel website built with HTML5, CSS3 and Vanilla JavaScript.

## Pages

- `index.html` — Home
- `packages.html` — All packages
- `package-details.html?id=ooty` — Dynamic package details
- `services.html` — Main services
- `taxi.html` — Taxi service
- `hotels.html` — Madurai hotel listings
- `reviews.html` — Customer reviews
- `about.html` — About
- `contact.html` — WhatsApp enquiry form

## Before client delivery

Edit `js/data.js`:

1. Business name
2. WhatsApp number
3. Phone
4. Email
5. Location
6. Hero image
7. Package data
8. Hotel data
9. Taxi details
10. Replace demo reviews with real customer reviews

## Important

The package, hotel and review information is demo/placeholder content because the client's final details were not supplied yet. Do not publish placeholder claims as real business facts.

## Running

Open `index.html` in a browser. For best local development, use VS Code Live Server.

No build step or npm installation is required.
